Release 1.2.1 

New two stage cadence loop timing algorithm with reference time calculation that ensures precise time synchronization and that self-corrects accumulated drift, interrupts and unforeseen delays.

Minor bug fixes and refactoring several functions for quality and memory optimization
Added several new functions and expanded several examples with more solution options
Expanded the documentation with detailed process drawings and additional explanations


Name changes:
-------------
set_PinOutputMode  changed to set_outputMode

get_pinOutputMode  changed to get_outputMode
get_pinOutputValue changed to get_outputValue
